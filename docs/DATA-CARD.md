# 数据卡（纯合成数据 v1.0.1）

## 来源与生成

- 生成器：`tools/build_synthetic_dataset.py`（确定性脚本，固定种子 `20261121-SYNTH`）；
- 参数：`synthetic/profile.json`，为作者设定的“某区域 A”一般水平假设；
- 不读取任何外部真实账套、申报明细、企业数据库或客户资料；
- 不对应任何真实项目或企业，不使用绝对年份（T1—T8）。

## 内容

- 8 期资产负债表、利润表、纳税申报表、合成凭证；
- 79 项确定性校验（报表恒等式、结转、借贷平衡、税务公式等）；
- 注入 3 类故障用于对照：抽取误差、税率歧义、回执延迟。

## 使用边界

- 仅用于方法演示与可复现性验证；
- 非官方统计，不可用于真实申报、审计、经营决策或对任何企业的评价；
- 不构成税务/会计/审计意见。
